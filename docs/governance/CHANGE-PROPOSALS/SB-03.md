# SB-03 — Second Brain / Knowledge Manager / Retrieval Engine Integration

**Status:** MERGED_TO_MAIN  
**Branch:** `proposal/second-brain-v3`  
**Base:** `main`

## Goal
Connect the SB-02 Second Brain contracts to the existing Knowledge Manager / Retrieval Engine boundary without creating a parallel RAG stack.

## Current State
- SB-02 defines KnowledgeItem, Evidence, Provenance, Validation, Relationship and AIAction contracts.
- Retrieval uses shared Citation/QueryHit models and a vector store with optional filters.
- Architecture assigns provenance/citation ownership to Knowledge Manager.
- The concrete Knowledge Manager implementation is not yet present as an independent runtime package; therefore SB-03 provides the integration adapter and retrieval policy contract rather than inventing a second Knowledge Manager.

## Scope
1. Map Second Brain knowledge metadata into retrieval records.
2. Build fail-closed retrieval filters for scope, case isolation, lifecycle status and validation status.
3. Preserve the existing Citation contract.
4. Add tests for mapping and case/validation isolation.
5. Document the integration boundary.

## Non-goals
- No replacement of the existing Retrieval Engine.
- No second vector database or second RAG.
- No PostgreSQL/pgvector migration.
- No direct merge to main outside the approved PR.
- No change to the existing Citation schema.

## Security / Fail-Closed Rules
- CASE scope requires the requested case_id to match exactly.
- CASE retrieval may include GLOBAL and DOMAIN knowledge, subject to validation/status policy.
- INVALID, CONFLICTING, SUPERSEDED and NEEDS_REVIEW knowledge is excluded by default.
- Only VALIDATED knowledge is eligible for the SB-03 trusted retrieval path.
- Unknown scope/status/validation values are rejected rather than silently admitted.
- No citation is synthesized for an unresolved source.

## Acceptance Criteria
- [x] Adapter exists.
- [x] Scope and case filters are deterministic.
- [x] Validation/lifecycle filtering is fail-closed.
- [x] Existing Citation model remains the citation contract.
- [x] Tests cover case isolation and invalid/conflicting/superseded exclusion.
- [ ] CI/runtime test execution in the project environment.
- [x] Human review / PR transition completed.
- [x] Merge to main completed.

## Dependencies
- SB-02 contracts on `proposal/second-brain-v2`.
- Existing shared Citation and retrieval contracts.
- Future concrete Knowledge Manager implementation can consume the adapter without changing the retrieval policy.

## Decision
Implement an adapter/policy boundary now. Keep persistence and vector-store migration as separate future change proposals.
